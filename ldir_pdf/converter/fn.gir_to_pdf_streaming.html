Convert a G-IR document to PDF, streaming output directly to a Write sink.

This is the streaming counterpart to gir_to_pdf_with_fonts_and_options. It writes PDF content sequentially to the sink, dropping page data as it goes, which reduces peak memory usage for large documents.
