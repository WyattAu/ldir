Module gir_to_scene 

Source
Expand description

G-IR to Vello Scene conversion.

Transforms G-IR command buffers into Vello Scene objects suitable for GPU rendering. Coordinates are converted from 26.6 fixed-point to f64 scene coordinates (divide by 64.0).
