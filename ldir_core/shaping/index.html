Module shaping 

Source
Expand description

Text shaping: HarfBuzz FFI, LRU cache, fast ASCII path. Text shaping integration (TASK-016, Phase A-2).

Provides the interface between text content and glyph layout. Uses HarfBuzz for real font-aware shaping with an ASCII fast-path for simple text (REQ-4.3.1.1).

All coordinates use Fp266 (26.6 fixed-point) per REQ-3.2.5 and THM-KP-DETERMINISM.
