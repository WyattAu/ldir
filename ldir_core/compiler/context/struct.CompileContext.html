Fields§

§x: Fp266

Current cursor X position (26.6 fixed-point).

§y: Fp266

Current cursor Y position (26.6 fixed-point).

§stack_depth: usize

Current stack depth (for PushStack/PopStack balance).

§page_width: Fp266

Current page width in 26.6 fixed-point.

§page_height: Fp266

Current page height in 26.6 fixed-point.

§font_size: Fp266

Current font size in 26.6 fixed-point.

§font_id: u32

Current font ID.

§content_width: Fp266

Usable content width (page width minus margins).

§font_data: Option<Arc<Vec<u8>>>

Raw font data for real shaping (ttf-parser + HarfBuzz). When None, falls back to ASCII monospace stub.

§font_data_variants: Vec<Option<Arc<Vec<u8>>>>

Font data per font ID (0=Regular, 1=Bold, 2=Italic, 3=BoldItalic, 4=Mono). Used for style-aware shaping in emit_paragraph.

§style_stack: Vec<StyleModifier>

Stack of active style modifiers (for nested bold/italic/mono).

§active_style: StyleModifier

Currently active combined style modifiers.

§pending_link_urls: Vec<String>

Pending link URLs for the current block, pre-scanned from LinkData children.

§link_start_positions: Vec<(f64, f64)>

Link start positions: (start_x, start_y) recorded before SetContent renders.

§margin_left: Fp266

Left margin in 26.6 fixed-point.

§margin_right: Fp266

Right margin in 26.6 fixed-point.

§margin_top: Fp266

Top margin in 26.6 fixed-point.

§margin_bottom: Fp266

Bottom margin in 26.6 fixed-point.

§footnote_reserve: i64

Additional reserved space at page bottom for footnotes (26.6 fixed-point).

§drop_caps_enabled: bool

Whether drop caps are enabled for paragraphs after headings.

§next_para_is_drop_cap: bool

Whether the next paragraph should be rendered as a drop cap.

§toc_page_count: usize

Number of pages consumed by the TOC (for page number offset).

§bump: Bump

Arena allocator for paragraph-scoped temporary allocations. Reset before each paragraph to reuse memory.

§shape_cache: ThreadSafeShapeCache

LRU cache for shaped text runs.

§interner: StringInterner

String interner for deduplicating repeated text across compilation.

§node_arena: Arena<u8>

Typed arena allocator for paragraph-scoped node/value allocations. Reset before each paragraph to reuse memory.

§string_arena: StringArena

String arena for zero-copy string interning during compilation. Reset between compilation passes to reuse memory.

§font_db: Option<Arc<FontDatabase>>

Font database for system font discovery and name-based lookup. When Some, the compiler can resolve font families by name.

§font_family: String

Primary font family name (e.g., “DejaVu Sans”). Used with font_db to resolve fonts by name.

§font_mono_family: String

Monospace font family name (e.g., “DejaVu Sans Mono”).

§template: PageTemplate

Page template for headers and footers.

§page_number: usize

Current page number (1-indexed).

§chapter_title: String

Current chapter title (for template expansion).

§section_title: String

Current section title (for template expansion).

§first_page: bool

Whether we are still on the first page (for header suppression).

§precomputed_paragraphs: HashMap<u32, PrecomputedParagraph>

Pre-computed paragraph layouts from the parallel phase. Keyed by node ID; populated before the sequential emit phase.

§opentype_features: Vec<Feature>

OpenType features to apply during text shaping (e.g., kern, liga, dlig). Empty vector means no feature overrides (HarfBuzz defaults apply).

pub fn new() -> Self

Create a new compilation context with default page dimensions. Uses ASCII monospace stub shaping (no real font data).

Source

pub fn with_font(font_data: Option<Arc<Vec<u8>>>) -> Self

Create a compilation context with real font data.

When font_data is Some, the compiler uses HarfBuzz + ttf-parser for real font-aware shaping. When None, falls back to the ASCII monospace stub.

Margins are specified in points.
