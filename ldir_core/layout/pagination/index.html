Global pagination algorithm (TASK-018).

Greedy page-breaking that accumulates paragraph blocks until page height is exceeded, then applies widow/orphan avoidance rules.

§Algorithm

  1. Accumulate paragraphs on the current page by total height
  2. When a paragraph doesn’t fit, check for orphan (first line alone at bottom of page) and widow (last line alone at top of new page)
  3. If detected, move the paragraph to the next page entirely
  4. Track demerits for suboptimal breaks
