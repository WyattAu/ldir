Paginate a sequence of paragraph blocks using a greedy algorithm.

§Algorithm

  1. Walk paragraphs in order, accumulating height on the current page
  2. When a paragraph doesn’t fit: a. If it’s the first item on the page, force it (overflow) b. Otherwise, check orphan (only first line fits at page bottom) c. Check widow (only last line would remain for next page) d. If orphan or widow, push paragraph to next page with demerits e. Finalize current page, start new page
  3. Finalize last page after all paragraphs are placed

§Panics

Does not panic. Returns empty PaginatedDocument for empty input or non-positive usable height.
