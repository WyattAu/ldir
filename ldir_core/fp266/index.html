26.6 fixed-point arithmetic for coordinates (REQ-3.2.5). fp26_6 Fixed-Point Arithmetic (REQ-3.2.5).

26.6 format: 26 integer bits + 6 fractional bits. Range: [-524288.0, 524287.9921875] Precision: 1/128 = 0.0078125 per unit in last place.

§Formal Specification

See YP-NUMERICAL-FIXEDPOINT-001 for the full theoretical treatment:

  • THM-FP-ADD-EXACT: Addition is exact (no rounding error)
  • THM-FP-MUL-ROUND: Multiplication error ≤ 0.5 ULP
  • THM-FP-SATURATION: Saturation prevents overflow
