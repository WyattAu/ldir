pub struct GlyphOutlineCache { /* private fields */ }
Expand description

LRU cache for glyph outlines.

Uses HashMap for O(1) lookup and a VecDeque-style access order for LRU eviction. Default capacity of 8192 covers typical documents.

pub fn get_or_compute<F>( &mut self, face_id: u64, glyph_id: u32, compute: F, ) -> &GlyphOutline
where F: FnOnce(u32) -> Option<GlyphOutline>,

Retrieves a cached outline or computes it via the provided closure.

On cache hit, the entry is promoted to most-recently-used. On cache miss, the closure is called with the glyph_id and the result is stored. If the cache is at capacity, the least-recently-used entry is evicted first.

Returns a reference to the cached outline. Panics if the compute closure returns None for a previously-uncached key.
