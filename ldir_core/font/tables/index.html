Manual OpenType kern, GPOS (kerning) and GSUB (ligature) table parsing.

Pure Rust fallback for WASM environments where HarfBuzz is unavailable. Parses the traditional kern table (Format 0), GPOS Lookup Type 2 (PairPos Formats 1 and 2), and GSUB Lookup Type 4 (LigatureSubst Format 1).
