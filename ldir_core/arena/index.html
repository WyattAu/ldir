Typed arena allocator and string arena for compilation hot paths. Typed arena allocator and string arena for compilation hot paths.

Provides O(1) bump allocation. No individual deallocation; drop the arena (or call crate::arena::Arena::clear) to free all memory at once.

§Design

Uses a chunked Vec<Vec<T>> backing store to avoid reallocation of the entire arena when a single chunk fills up. Items within a chunk are contiguous and cache-friendly.
