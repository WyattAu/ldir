ldir -- The LLVM of Documents

A universal intermediate representation for deterministic document typesetting.

Overview

ldir is a compiler infrastructure for documents. It defines a three-layer intermediate representation (S-IR, L-IR, G-IR) that decouples input parsing from output rendering, enabling format-agnostic optimization, validation, and transformation.

Architecture

Input --> [Parser] --> S-IR v2 --> [Compiler] --> L-IR --> [Renderer] --> PDF / HTML / EPUB / ...

Supported Formats

Input (9)Markdown, LaTeX, Typst, HTML, Asciidoc, Org-mode, DOCX, SIR2, LDIR
Output (8)PDF, HTML, EPUB, TXT, DOCX, GIR, SIR2, LDIR

Quick Start

cargo install --path ldc
ldc input.md -o output.pdf

Formal Verification

IR well-formedness properties are formally verified in Lean 4. All proofs compile with 0 sorry. Verified properties include entity uniqueness, parent reference validity, acyclicity, single-root constraint, and compiler termination.
