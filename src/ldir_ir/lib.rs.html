1//! # ldir-ir
2//!
3//! IR type definitions for the LDIR document pipeline: S-IR, L-IR, and G-IR
4//! with rkyv serialization support.
5
6#![warn(clippy::unwrap_used, clippy::expect_used)]
7//!
8//! This crate defines three layers of intermediate representation used
9//! throughout the LDIR compilation pipeline:
10//!
11//! - **S-IR** (Source IR): Tree-structured document representation with
12//!   13-byte fixed-cost instruction headers. Instructions reference each other
13//!   via entity IDs and parent pointers, forming a tree rooted at the entity
14//!   whose `parent_id == ROOT_SENTINEL`.
15//! - **L-IR** (Layout IR): Positioned box tree capturing all layout decisions
16//!   as explicit 26.6 fixed-point geometry.
17//! - **G-IR** (Graphical IR): Flat, per-page command buffer with 36-byte
18//!   structs containing an opcode and 8 x i32 argument slots.
19//!
20//! ## Key Types
21//!
22//! - [`sir::SIRDocument`] / [`sir::SIRInstruction`] — S-IR document and instruction types
23//! - [`sir::SIROpcode`] / [`sir::BlockType`] — S-IR opcodes and block classifications
24//! - [`sir::StyleModifier`] — Inline style flags (bold, italic, mono)
25//! - [`lir::LIRDocument`] / [`lir::LIRNode`] — L-IR layout tree with 23 node types
26//! - [`fp266::Fp266`] — 26.6 fixed-point number for geometry
27//! - [`gir::GIRDocument`] / [`gir::GIRCommand`] — G-IR rendering command buffer
28//!
29//! ## Quick Start
30//!
31//! ```rust
32//! use ldir_ir::sir::{SIRDocument, SIRInstruction, SIROpcode, BlockType, ROOT_SENTINEL};
33//!
34//! let mut doc = SIRDocument::new();
35//! let payload_off = doc.payload_mut().append(&[BlockType::Document as u8]);
36//! doc.push(SIRInstruction::new(SIROpcode::PushBlock, 0, ROOT_SENTINEL, payload_off));
37//! doc.push_with_payload(
38//!     SIRInstruction::new(SIROpcode::SetContent, 1, 0, 0),
39//!     b"Hello, world.",
40//! );
41//! ```
42//!
43//! ## Wire Format
44//!
45//! S-IR instructions use a 13-byte wire-format header (REQ-3.1.2):
46//! - OpCode: 1 byte
47//! - EntityID: 4 bytes (u32)
48//! - ParentID: 4 bytes (u32, sentinel 0xFFFFFFFF for root)
49//! - PayloadOffset: 4 bytes (u32)
50//!
51//! G-IR commands use a 36-byte struct with 8 x i32 argument slots.
52//! Wire format is 16-byte aligned (REQ-3.2.2).
53//!
54//! ## Serialization
55//!
56//! S-IR types implement `rkyv::Archive`, `rkyv::Serialize`, and
57//! `rkyv::Deserialize` for zero-copy deserialization. G-IR uses a
58//! custom binary format emitted by `ldir_core::emitter::emit_gir`.
59//!
60//! ## Formal Verification
61//!
62//! Type well-formedness is specified in Lean 4:
63//! - `entityUnique`: All entity IDs are distinct (AX-001)
64//! - `parentExists`: Every parent reference is valid (AX-002)
65//! - `isAcyclic`: No circular parent chains (AX-003)
66//! - `hasSingleRoot`: Exactly one root node exists (DEF-004.5)
67//!
68//! ## References
69//!
70//! - [Repository](https://github.com/WyattAu/ldir)
71//! - YP-IR-SEMANTICS-001: IR Type Semantics and Well-Formedness
72//! - REQ-3.1.x: S-IR specification
73//! - REQ-3.2.x: G-IR specification
