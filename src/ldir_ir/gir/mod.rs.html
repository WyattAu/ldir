1//! G-IR (Graphical Intermediate Representation) type definitions.
2//!
3//! Linearized rendering command sequence with page-based structure.
4//!
5//! ## Module Structure
6//!
7//! - `opcode`: G-IR opcode enum (REQ-3.2.3)
8//! - `command`: G-IR command struct with fixed-size args
9//! - `page`: G-IR page with stack balance validation (DEF-002)
10//! - `document`: G-IR document (DEF-003)
11//! - `style`: Style types for font/size/color
12//!
13//! ## Well-Formedness (DEF-005)
14//!
15//! A document is well-formed iff all pages satisfy:
16//! 1. Coordinates are in 26.6 representable range.
17//! 2. Font precedence is maintained.
18//! 3. Coordinate stack is balanced.
19//! 4. Coordinates are within page bounds.
