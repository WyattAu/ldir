1//! # ldir-pdf
2//!
3//! PDF generation backend for the LDIR document pipeline. Converts G-IR
4//! rendering commands into valid PDF files with embedded TrueType fonts,
5//! ToUnicode CMaps for text extraction, and FlateDecode compression.
6
7#![warn(clippy::unwrap_used, clippy::expect_used)]
8// warn pending full API documentation — re-tighten when complete
9#![warn(missing_docs)]
10#![deny(unsafe_code)]
11//!
12//! ## Key Types
13//!
14//! - [`converter::gir_to_pdf`] — Convert G-IR to PDF bytes (fallback Helvetica)
15//! - [`converter::gir_to_pdf_with_fonts`] — Convert with embedded TrueType fonts
16//! - [`conformance::PdfConformance`] — PDF/A conformance level (4, 2b, 3b)
17//! - [`converter::PdfOptions`] — PDF metadata and header/footer configuration
18//! - [`font::FontFace`] — TrueType font handle for embedding
19//! - [`lir_render::render_lir_to_gir`] — Convert L-IR layout tree to G-IR
20//! - [`image::ImageData`] — Decoded image data for embedding
21//!
22//! ## Quick Start
23//!
24//! ```rust,ignore
25//! use ldir_pdf::converter::gir_to_pdf;
26//!
27//! // Convert a G-IR document to PDF (fallback Helvetica)
28//! let pdf_bytes = gir_to_pdf(&gir_doc);
29//! std::fs::write("output.pdf", &pdf_bytes).unwrap();
30//! ```
31//!
32//! ## Features
33//!
34//! - TrueType font embedding (Type0 + CIDFontType2)
35//! - Multiple font variants: Regular, Bold, Italic, BoldItalic, Mono
36//! - ToUnicode CMap generation for text extraction
37//! - FlateDecode stream compression
38//! - PNG and JPEG image embedding
39//! - PDF/A-4 logical structure
40//! - L-IR to G-IR rendering pipeline
41//!
42//! ## References
43//!
44//! - [Repository](https://github.com/WyattAu/ldir)
