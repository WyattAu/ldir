# ldir-lsp

LDIR Language Server Protocol server — provides IDE support for Markdown, TeX, and Typst documents using the LDIR pipeline.

## Features

- LSP server for document language support
- Supports Markdown, TeX, and Typst
- Integrates with editors that support the Language Server Protocol
