CLI Reference

Usage

ldc [OPTIONS] <INPUT>

Arguments

ArgumentDescription
INPUTInput file path. Format is auto-detected from file extension.

Configuration File

Configuration uses TOML format. Create ldir.toml (or .ldir.toml) in your project root:

[output]
format = "pdf"
pdfa_level = "2b"
pdf_version = "1.7"

[layout]
columns = 2
page_width = "210mm"
page_height = "297mm"
margin = "25mm"

[typography]
font_size = "11pt"
line_height = 1.5
ot_features = "kern,liga"

[fonts]
path = "/usr/share/fonts/MyFont.ttf"

Configuration Priority

  1. CLI flags (highest)
  2. ./ldir.toml or ./.ldir.toml (searches current and parent directories)
  3. $XDG_CONFIG_HOME/ldir/config.toml (~/.config/ldir/config.toml)

Use ldc --dump-config to inspect the final merged configuration.
