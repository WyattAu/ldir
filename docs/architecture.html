Architecture

ldir uses a three-layer intermediate representation pipeline that decouples input parsing from output rendering. This enables format-agnostic optimization, validation, and transformation.

Three-Layer IR

S-IR (Semantic IR)

The first layer captures document semantics independent of any rendering target:

  • Document structure (headings, paragraphs, lists, tables, figures)
  • Styles (font family, size, weight, color, spacing)
  • Cross-references and citations
  • Bibliography entries (IEEE, APA, Chicago styles)
  • Mathematical expressions
  • Image and media references

S-IR uses f64 for semantic precision -- values represent logical units (points, millimeters) rather than pixels.

L-IR (Layout IR)

The second layer captures page-level layout decisions:

  • Page geometry (width, height, margins)
  • Line and column breaks (Knuth-Plass algorithm)
  • Multi-column reflow with balanced content
  • Full-width spanning elements
  • Positioned elements (floats, footnotes, margins)
  • Dirty-subtree tracking for incremental re-layout

G-IR (Graphics IR)

The third layer captures rendering commands:

  • Font references and glyph positioning
  • Path operations (fill, stroke, clip)
  • Image placement and scaling
  • Color management
  • Page-level rendering commands

G-IR uses Fp26.6 (26.6 fixed-point) for pixel-exact rendering. All floating-point coordinates are quantized to sub-pixel precision to ensure deterministic, platform-independent output.

Key Design Decisions

Precision Model

  • S-IR: f64 for semantic precision -- represents logical units
  • G-IR: Fp26.6 fixed-point for pixel-exact rendering
  • This separation ensures deterministic output: the same S-IR always produces bit-identical PDF/HTML regardless of platform

Line Breaking

Knuth-Plass line breaking with a configurable penalty model supports:

  • Optimal line breaks minimizing total demerits
  • Hyphenation integration (5 languages + Liou patterns)
  • Multi-column balanced reflow

Streaming Output

The PDF writer uses a streaming architecture for constant-memory output regardless of document size. Pages are finalized and flushed sequentially without buffering the entire document in memory.

Formal Verification

Lean 4 proofs in ldir-proofs/ verify IR well-formedness properties with 0 sorry:

  • S-IR structural invariants
  • G-IR rendering command validity
  • Layout constraint satisfaction
