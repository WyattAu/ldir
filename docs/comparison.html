Notes

  • Input/output format counts refer to natively supported formats built into the tool, not formats achievable through third-party extensions or shell pipelines.
  • Compilation speed is a qualitative characterization based on typical single-document builds. Actual performance depends on document size, complexity, and available hardware.
  • Macro system refers to the user-facing extensibility mechanism for text transformation during compilation.
  • Plugin system refers to the mechanism for loading and executing sandboxed external code to extend input parsing, output generation, or compilation behavior.
  • IR pipeline indicates whether the tool uses an intermediate representation layer between parsing and rendering. ldir's three-layer pipeline (semantic, layout, rendering) enables independent optimization and verification at each stage.
  • Formal verification indicates that correctness properties of the IR are proven using a proof assistant (Lean 4 for ldir). This does not imply that the entire tool chain is formally verified.
