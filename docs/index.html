LDIR.

THE LLVM OF DOCUMENTS

A compiler infrastructure for documents. Defines a three-layer intermediate representation (S-IR, L-IR, G-IR) that decouples input parsing from output rendering, enabling format-agnostic optimization, validation, and transformation.

INPUT → [PARSER] → S-IR v2 → [COMPILER] → L-IR → [RENDERER] → PDF / HTML / EPUB / ...
cargo install --path ldc # or: cargo install ldc
ldc input.md -o output.pdf

Verification
