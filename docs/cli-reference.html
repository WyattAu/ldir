Getting Started

Prerequisites

  • Rust 1.88+ (edition 2024, resolver 3)
  • A C compiler (for harfbuzz-sys FFI)
The minimum supported Rust version (MSRV) is 1.88. Earlier versions are not supported.

Installation

From Source (Recommended)

git clone https://github.com/WyattAu/ldir.git
cd ldir
cargo install --path ldc

From crates.io

cargo install ldc

Your First Compilation

Create a simple Markdown file:

# Hello, ldir

This is a paragraph with **bold** and *italic* text.

- Item one
- Item two
- Item three

```rust
fn main() {
    println!("Hello from ldir!");
}
```

Compile it to PDF:

ldc input.md -o output.pdf

Compile to other formats:

ldc input.md -o output.html
ldc input.md -o output.epub
ldc input.md -o output.txt
ldc input.md -o output.docx

PDF/A Compliance

Generate PDF/A-compliant output for archival:

ldc input.md --pdfa-level 2b -o output.pdf

Supported PDF/A levels:

  • 1b -- PDF/A-1b (basic)
  • 2b -- PDF/A-2b (recommended)
  • 3b -- PDF/A-3b (with attachments)
  • off -- no PDF/A compliance (default)

Configuration File

Create ldir.toml in your project directory:

[output]
format = "pdf"
pdfa_level = "2b"

[layout]
columns = 2
page_width = "210mm"
page_height = "297mm"
margin = "25mm"

[typography]
font_size = "11pt"
line_height = 1.5

Configuration is read from (in priority order):

  1. CLI flags (highest priority)
  2. ./ldir.toml or ./.ldir.toml in the current or parent directories
  3. $XDG_CONFIG_HOME/ldir/config.toml (usually ~/.config/ldir/config.toml)

Dump the effective merged configuration:

ldc --dump-config

Shell Completions

Shell completions for bash, zsh, fish, and PowerShell are available via clap-complete. Generate them with the provided example:

cargo run --example generate-completions

Development

# Build all crates
cargo build --workspace

# Run tests (1,909 tests)
cargo test --workspace

# Lint (0 warnings)
cargo clippy --workspace -- -D warnings

# Format check
cargo fmt --check
