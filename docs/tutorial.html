Tutorial v0.1.0

This tutorial walks you through common ldir tasks from a blank file to a multi-section document with math, tables, cross-references, and citations. Each section is self-contained -- copy the examples into a .md file and compile them.

Your First Document

Create a file called hello.md:

# Hello, ldir

This is my first document compiled with ldir.

- It supports **bold**, *italic*, and `inline code`.
- Lists and headings work exactly as in standard Markdown.

That is all there is to it.
Run the compiler and open the resulting PDF.

Compile to PDF:

ldc hello.md -o hello.pdf

The output is a typeset PDF with default A4 page size, 12pt body text, and hyphenation enabled.

Adding Math

ldir renders LaTeX math expressions in Markdown. Use dollar signs for inline math and double dollar signs for display equations.

# Mathematics in ldir

The quadratic formula solves $ax^2 + bx + c = 0$:

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

Euler's identity: $e^{i\pi} + 1 = 0$.

A matrix:

$$
A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}
$$

Compile:

ldc math.md -o math.pdf


    
Supported math environments: $...$ (inline),
    $$...$$ (display), and \begin{align}...\end{align}
    for numbered multi-line equations.


    
Creating Tables


    
Standard Markdown table syntax is supported:



# Sales Report

| Quarter | Revenue | Growth |
|---------|---------|--------|
| Q1      | $1.2M   | 5%     |
| Q2      | $1.5M   | 25%    |
| Q3      | $1.8M   | 20%    |
| Q4      | $2.1M   | 17%    |

| :---           | ---:  | :---: |
| Left-aligned   | Right | Center |
| data           | 100   | ok    |


    
Pipe tables and simple grid tables are both supported. Column
    alignment is controlled by the separator row (:---,
    ---:, :---:).


    
Cross-References


    
Use \label{} and \ref{} to create
    cross-references between sections, figures, and tables.



# Introduction \label{sec:intro}

This is the introduction. See Section \ref{sec:methods} for
the methodology.

## Methods \label{sec:methods}

We used the approach described in Section \ref{sec:intro}.

## Results

As shown in Table \ref{tab:results}:

| Metric | Value |
|--------|-------|
| Accuracy | 97.3% |
| Recall | 95.1% |
\label{tab:results}


    
References are resolved during compilation and rendered as numbered
    links. The \label can appear on a heading line or
    immediately after a table.


    
Citations and Bibliography


    
ldir reads BibTeX .bib files and renders citations
    using IEEE, APA, or Chicago styles.


    
Create refs.bib:



@article{knuth1984,
  author  = {Knuth, Donald E.},
  title   = {Literate Programming},
  journal = {The Computer Journal},
  year    = {1984},
  volume  = {27},
  number  = {2},
  pages   = {97--111},
}

@book{lamport1994,
  author    = {Lamport, Leslie},
  title     = {{\LaTeX}: A Document Preparation System},
  publisher = {Addison-Wesley},
  year      = {1994},
  edition   = {2},
}


    
Create paper.md:



# Related Work

The concept of literate programming was introduced by
Knuth \cite{knuth1984}. For document preparation,
\cite{lamport1994} describes the widely-used LaTeX system.

## References

\bibliography{refs}
\bibliographystyle{ieee}


    
Compile with the bibliography:



ldc paper.md -o paper.pdf


    
Available styles: ieee, apa,
    chicago. Year disambiguation is handled automatically
    when multiple works by the same author share a year.


    
Configuration


    
Project-level settings are stored in ldir.toml in the
    same directory as your source file.



[document]
title = "My Document"
author = "Jane Doe"
date = "2026-05-31"
paper-size = "a4"
margin-top = "2.5cm"
margin-bottom = "2.5cm"
margin-inner = "3cm"
margin-outer = "2cm"

[typography]
font-body = "Latin Modern Roman"
font-heading = "Latin Modern Sans"
font-mono = "Latin Modern Mono"
font-size = "12pt"
line-height = 1.5

[output]
format = "pdf"
pdf-a = "2b"
hyphenation = "en"


    
When ldir.toml is present, ldc reads it
    automatically. CLI flags override file settings.


    
Output Formats


    
ldir supports multiple output formats. The -o flag
    determines the format based on the file extension:



# PDF (default)
ldc input.md -o output.pdf

# HTML
ldc input.md -o output.html

# EPUB
ldc input.md -o output.epub

# DOCX (Word)
ldc input.md -o output.docx

# ODT (LibreOffice)
ldc input.md -o output.odt

# Plain text
ldc input.md -o output.txt


    
All formats share the same compilation pipeline -- Markdown, LaTeX,
    Typst, or HTML input is parsed into S-IR, compiled to L-IR, and then
    rendered to the target format. This means a single source file can
    produce consistent output in any supported format.
