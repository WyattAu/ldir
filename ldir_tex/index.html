§ldir-tex

TeX/LaTeX to S-IR parser for the LDIR document pipeline. Converts a practical subset of LaTeX into an S-IR document tree suitable for compilation by ldir-core.

§Key Types

  • parse_tex — Main entry point: LaTeX string to S-IR document

§Quick Start

use ldir_tex::parse_tex;

let doc = parse_tex(r"\section{Introduction}\textbf{Bold text}.");
println!("Parsed {} S-IR instructions", doc.len());
