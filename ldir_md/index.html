§ldir-md

Markdown to S-IR parser for the LDIR document pipeline. Converts CommonMark Markdown (with GFM extensions) into an S-IR document tree suitable for compilation by ldir-core.

§Key Types

  • parse_markdown — Main entry point: Markdown string to S-IR document

§Quick Start

use ldir_md::parse_markdown;

let doc = parse_markdown("# Hello\n\nThis has **bold** text.");
println!("Parsed {} S-IR instructions", doc.len());
