ldir_ir::lir

Module types 

Source
Expand description

LIR node type definitions (YP-LAYOUT-LIR-001 Section 5).

All 23 LIR box types plus supporting types (LIRGeometry, LIRNode enum, LIRDocumentMeta, TOCEntry). Each node carries resolved positions and sizes in 26.6 fixed-point per AX-LIR-001.
