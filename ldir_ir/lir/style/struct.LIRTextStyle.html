Expand description

Resolved text style properties for a glyph run.

Referenced by style_id: u32 on LIR nodes. The style table on LIRDocument holds the full set of resolved styles.

Fields§

§id: u32

Unique style identifier.

§font_id: u32

Font resource identifier.

§font_size: Fp266

Font size in 26.6 fixed-point.

§color_rgba: u32

Text color as packed RGBA (0xRRGGBBAA).

§bold: bool

Bold weight.

§italic: bool

Italic slant.

§underline: bool

Underline decoration.

§strikethrough: bool

Strikethrough decoration.

§small_caps: bool

Small capitals variant.

§letter_spacing: Fp266

Extra spacing between letters.

§word_spacing: Fp266

Extra spacing between words.

§line_height: Fp266

Line height (baseline-to-baseline distance).
